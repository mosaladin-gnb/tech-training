# Tech Training

Interactive, self-paced resources for a workplace technology training series. Each session gets one page: the facilitator presents from it live, and the same page is the reference afterwards.

**Live:** https://mosaladin-gnb.github.io/tech-training/

## What these are

Short explorations of a tool — what it can do, which parts people actually use, and how it fits into everyday work. Not a course. Nothing is scored, nothing is recorded, and nothing here is a test.

Each page works two ways:

- **In the session** — presented on screen, card by card.
- **On your own** — labs, step checklists and a short exercise you can work through at your own pace, including from a recording.

The beginner path runs straight down the page. Anything more advanced sits behind collapsible **Go deeper** sections, closed by default.

## How to use a page

Open the live link, or download the `index.html` file and open it in any browser. There is nothing to install.

Each file is self-contained — fonts, styles, scripts and images are all inline — so it works offline and from a Downloads folder.

Your place in the page, your notes and your exercise answers are saved in your own browser only. They are not sent anywhere and nobody else can see them. Clearing site data clears them.

## Accessibility

Built to WCAG 2.1 AA:

- Real heading elements, in order
- Alt text on every image
- Colour is never the only way information is carried
- Text contrast meets AA in both light and dark modes
- Keyboard navigation throughout, arrow keys to move between cards
- Motion disabled when your system asks for reduced motion
- Works at phone width

If something here is hard to use, that is a defect — please open an issue.
